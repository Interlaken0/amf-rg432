Software-engineering process evidence: pull requests, continuous
integration, automated versioning, and packaged releases.

## What this demonstrates

- Agile process: sprint branches → PRs → squash merges → tags → releases
- CI/CD that runs quality gates automatically, not on request
- A diagnosed-and-fixed CI race condition (release job pushing from a
  superseded commit — resolved by deleting the orphaned tag and
  re-running the tip run)
- Release management: versioned, checksummed, downloadable artefacts
